# cAm-DiGEan
An end-to-end workflow for the Differential Gene Expression analysis of a Salmo salar Custom Affymetrix Microarray

This workflow is based on the maEndToEnd workflow (https://github.com/b-klaus/maEndToEnd)

The workflow was developed and tested in R version 4.5.1.
All libraries were individually installed via R *install.packages()* and *library()* functions, unless otherwise explicited in the code that were retrieved via BioConductor.
